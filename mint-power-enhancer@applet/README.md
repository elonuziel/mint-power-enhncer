# Mint Power Enhancer Cinnamon Applet

This folder contains the Cinnamon panel applet version of Mint Power Enhancer.

## What it does
- Lives in the Cinnamon panel
- Shows battery status and active power mode
- Can switch Battery Saver and Performance Mode automatically
- Persists settings with Cinnamon's settings system

## Requirements
See [DEPENDENCIES.md](DEPENDENCIES.md).

## Install
From inside this folder:

```bash
bash install.sh
```

That copies the applet into Cinnamon and enables it on the panel.

## Uninstall

```bash
bash install.sh --uninstall
```
